# CJ THE MARKET

CJ THE MARKET을 참고하여 제작한  
반응형 쇼핑몰 웹 퍼블리싱 포트폴리오입니다.

## 📌 프로젝트 소개

HTML, CSS, JavaScript를 활용하여  
쇼핑몰 메인 페이지와 상품 상세페이지를 구현했습니다.

## 🛠 사용 기술

- HTML5
- CSS3
- JavaScript
- JSON
- Git / GitHub

## ✨ 주요 기능

- 메인 배너 슬라이드
- 상품 리스트 출력
- JSON 데이터를 활용한 상품 렌더링
- 상품 상세페이지
- 메인 → 상품 상세페이지 이동
- 수량 선택 기능
- 모바일 반응형 레이아웃

## 📱 반응형 웹

PC와 모바일 화면 크기에 맞춰  
레이아웃이 변경되도록 제작했습니다.
